# 电商与库存体验版接口约定

日期：2026-11-03。内部实现约定，业务规则见架构目录设计方案。

新接口前缀 `/api/operations`，使用现有 JWT，读权限 `operations:view`，库存写 `inventory:write`，销售写 `sales:write`，活动写 `campaign:write`；管理员 `*` 通用。

新接口采用 snake_case 字段。列表 GET 接受 `q,page,size`（10/20/50），返回 `{items,total}`。金额为十进制字符串。错误返回 Nest 错误格式。

公共：GET `/catalog?q=&page=` 返回 `{items:[{id,sku,name,material_code,kind}],hasMore}`，每页20条；GET `/warehouses` 返回 `[{id,name}]`。

库存：GET `/stock` 返回 `{items:[{product_id,sku,name,material_code,in_stock,available,reserved,pending,borrowed}],total}`。
GET `/units?product_id=&status=&q=&page=&size=` 返回 `{items:[{id,product_id,sku,name,serial_number,batch_number,status,warehouse_id,warehouse_name,parent_id}],total}`。状态 available/reserved/pending/borrowed/shipped/assembled/scrapped。
GET `/movements` 返回 `{items:[{id,number,type,reason,occurred_at,created_at,recipient,sales_order_id,carrier,tracking_number,shipping_cost,notes,items}],total}`。
POST `/receipts` `{type:purchase|initial|return|borrow_return,warehouse_id,occurred_at,recipient,notes,items:[{product_id,batch_number,serial_numbers:string[]}]}`。每次均提交完整操作并过账。
POST `/issues` `{type:sale|sample|borrow|internal|scrap,warehouse_id,occurred_at,recipient,reason,expected_return_at?,sales_order_id?,carrier,tracking_number,shipping_cost,notes,unit_ids:string[]}`。
POST `/assemblies` `{product_id,serial_number,batch_number,warehouse_id,occurred_at,unit_ids:string[],notes}`；POST `/disassemblies` `{unit_id,occurred_at,reason}`。
GET `/trace?q=` 返回 `{units:[{...单件字段,history:[{number,type,occurred_at,recipient,reason,notes,carrier,tracking_number}],components:[单件字段]}]}`，搜索同序列号多个型号返回多项。

销售：GET `/orders` 返回 `{items:[{id,number,external_number,channel,store_id,store_name,customer_name,ordered_at,status,original_amount,discount_amount,paid_amount,shipping_amount,refunded_amount,notes,items,discounts}],total}`；GET `/orders/:id` 同单条，包含发货明细。
POST `/orders` `{external_number,channel,store_id?,customer_name,ordered_at,shipping_amount,notes,items:[{product_id,quantity,unit_price,campaign_id?}],discounts:[{name,amount,bearer:merchant|platform,product_id?}],discounts_complete:boolean,paid_amount}`。
POST `/orders/:id/cancel` 取消未发货订单；POST `/orders/:id/refunds` `{amount,reason}` 只退款不动库存。
GET `/stores` 返回数组；POST `/stores` `{platform,name}`。

活动：GET `/campaigns` 返回 `{items:[{id,name,store_id,store_name,starts_at,ends_at,status,notes,version,items}],total}`。
POST `/campaigns` `{name,store_id,starts_at,ends_at,notes,items:[{product_id,list_price,rules:[{name,type:fixed|percent|threshold,amount,threshold?,cap?,bearer:merchant|platform,exclusive_group?}]}]}`；PATCH `/campaigns/:id` 同体，修改创建版本快照；POST `/campaigns/:id/publish` 发布；POST `/campaigns/:id/archive` 归档。
POST `/campaigns/:id/preview` `{product_id,quantity,rule_indexes:number[]}` 返回 `{original_amount,discounts:[{name,amount,bearer}],discount_amount,paid_amount}`，按配置顺序运算，percent 的 amount 表示减免百分比；门槛按优惠前金额；互斥组不允许同时使用。
GET `/campaign-stats?campaign_id=` 返回 `{items:[{product_id,sku,name,ordered_quantity,shipped_quantity,returned_quantity,original_amount,discount_amount,paid_amount,merchant_discount,platform_discount}],totals:{...},discounts:[{name,count,amount}],incomplete_orders}`。不把预计优惠计入实际。

数据库：新模块全部使用独立 ops_ 前缀表、schema 为 DB_SCHEMA。公共 OpsDatabase 提供 `table(name):string` 和 `db:DataSource`；所有用户数据均参数绑定。库存服务可在事务中查询 ops_sales_orders、ops_sales_order_items；订单行至少 id/order_id/product_id/quantity/unit_price/original_amount/discount_amount/paid_amount/campaign_id/campaign_snapshot，订单 status 为 open/partial/shipped/cancelled。库存出库写 movement 的 sales_order_id，并更新订单状态。

所有已过账操作保留不可覆盖流水；金额 Decimal；时间合法性、UUID、正整数、唯一性与并发必须校验。新增材料编码在 products.material_code，实体字段 materialCode。

## 联调后补充约定

- `/catalog?id=UUID` 支持编辑表单按 ID 恢复当前商品，返回相同列表格式。
- `/units` 支持 `warehouse_id`、`reserved_order_id` 精确筛选；`status=dispatchable&dispatch_order_id=UUID` 返回可用实物及该订单自己预留的实物。
- `POST /reservations` 和 `POST /releases`：`{sales_order_id,unit_ids,warehouse_id,occurred_at,reason}`。取消订单在同一事务内自动释放预留。
- `POST /inspections`：`{unit_id,warehouse_id,occurred_at,result:available|scrapped,reason}`，仅待检实物可操作。
- `POST /bundle-components`：`{unit_id,unit_ids,warehouse_id,occurred_at,reason}`，补齐直接入库套装的实际组成；单件返回 `traceability_pending`，拆套状态为 `disassembled`。
- `/disassemblies` 需传 `warehouse_id`；借样出库需填写晚于发生时间的 `expected_return_at`。
- 订单新增可选 `recipient_phone`、`shipping_address`；订单和商品行返回 `undisclosed_discount_amount`，作为实际实付与已知券明细之间的待补差额。
- `POST /orders/:id/discounts`：`{discounts,discounts_complete:true}`，仅用于待补优惠订单；保留补录前版本，完整明细需与原实付核对一致。
- `/campaign-stats` 支持 `from`、`to`（结束时间不含）、`store_id` 筛选，返回净发货及关联订单级退款合计，退款不虚构商品分摊。
- 库存业务单据确认即过账；当前接口不提供已过账单据覆盖修改或删除。
