# 文档导航

首期范围、当前已确认的业务规则和验收标准，以[开发执行规格](implementation/简易PLM系统开发规格-代理执行版.md)为准。其他版本文档保留为设计过程记录；发生冲突时，以开发执行规格为准。

## 目录

- `implementation/`：当前开发执行规格，是开发代理的主要依据。
- `requirements/`：功能需求方案的历史版本（V0.2–V1.1）。
- `architecture/`：技术选型、系统架构和实施方案的历史版本。
- `reference/`：业务参考资料，包括原始报价工作簿。

项目部署、环境配置和数据库初始化步骤见仓库根目录的 [README](../README.md)。
