# 简易 PLM 系统功能需求方案

版本：V0.7（业务讨论稿）  
日期：2026-11-01  
状态：需求待进一步确认，尚未进入系统架构设计与开发

## 1. 建设目标

统一管理产品资料、工厂采购基准价（即出厂价）、财务含税成本及客户报价，减少资料分散、价格口径不统一和报价等待时间。首期支持产品、配件、组合商品、自有品牌及客户贴牌报价。基础数据允许不完整，向客户提供的每个产品报价必须经过人工确认。

## 2. 首期范围

- 产品、配件、组合商品及规格、组成资料管理。
- 采购基准价（即出厂价）、财务含税成本、销售价格规则及阶梯价格管理。
- 组合商品按不同价格口径和数量档生成参考价格。
- 客户资料、品牌资料、自有品牌及客户专属贴牌价格配置。
- 自有品牌（白牌）与客户贴牌两个报价页签，生成、逐项确认、导出及查询报价单。
- 长期价格调整、本次报价专用价格调整，以及价格和报价记录追溯。

暂不纳入：包装类字段及包装物料管理、销售最小单位字段、在报价单表格内直接修改价格、自动确认客户报价。贴牌定制说明和必要费用参数属于报价规则，不等于建立包装物料管理。系统架构及开发待业务需求确认后另行讨论。

## 3. 商品与规格

### 3.1 商品类型

| 类型 | 定义 | 组成 |
| --- | --- | --- |
| 产品 | 可独立管理或销售的成品 | 可维护产品及配件组成 |
| 配件 | 产品配套、维修或可独立销售的零部件 | 是否允许继续拆分待确认 |
| 组合商品 | 将产品或配件按指定数量组合销售的商品 | 维护组成项及用量 |

商品身份与组成关系分开管理：标准成品可以维护组成；销售套装也可以建为组合商品。组成关系不允许循环引用。是否允许组合商品嵌套组合商品待确认。

### 3.2 商品字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 列表展示顺序，不作为业务编号 |
| 货号／型号 | 工厂或公司使用的业务编号 |
| 品名、图片 | 商品名称与主图 |
| 规格及描述 | 型号、配置等说明 |
| 单位 | 如台、只、套；作为计价单位 |
| 商品类型、状态 | 产品／配件／组合商品；草稿、启用、停用 |
| 备注、更新时间 | 业务说明和追溯 |

参考表中同一型号有单只和双只规格，单位与价格不同。建议以商品及规格区分可报价项目，分别维护单位、价格与组成；编码唯一性规则待确认。停用商品不能加入新报价，历史报价仍保留。

### 3.3 品牌

白牌页签用于公司自有品牌报价，现有示例为毅诺品牌；系统不能将品牌固定为毅诺，后续可以维护多个自有品牌。客户贴牌指按客户要求使用客户品牌的报价。品牌、商品规格、客户及报价价格应可关联；品牌是否改变产品规格或仅影响销售价格，按实际业务进一步确认。

## 4. 价格定义

| 价格或概念 | 定义及规则 |
| --- | --- |
| 采购基准价／出厂价 | 同一个价格概念，是从工厂获取、由人工录入的采购价，也是销售报价的基础价格；以下统一称“采购基准价（出厂价）”。可以暂时缺失 |
| 财务报含税价（成本） | 财务提供的含税成本，单独维护，可暂时缺失；不默认与采购基准价相等 |
| 出厂价 | 人工录入并单独维护；其与采购基准价、销售报价的关系待确认 |
| 自有品牌报价 | 基于基础价格及自有品牌的价格配置，按数量阶梯产生的客户报价候选价 |
| 客户贴牌报价 | 基于基础价格及对应客户的个性化价格配置，按同一阶梯匹配逻辑产生的客户报价候选价 |
| 报价人工确认 | 对报价单中每个产品生成的价格进行人工核对和确认，是单次报价的保障，不另定义为一种长期价格 |
| 市场零售参考价 | 按出厂价及加价比例生成，供参考；不自动成为已确认的客户报价 |

价格记录应明确商品规格、计价单位、币种、含税口径、生效时间和来源；是否需要税率、失效时间、供应商维度待确认。缺失价格不按零计算。

市场零售参考价预设在出厂价基础上加价 50%、80%、100%、180%，公式为出厂价 ×（1＋加价比例）。出厂价缺失时不生成有效参考价。

## 5. 价格配置与阶梯

### 5.1 共用计算流程

自有品牌和客户贴牌采用相同的计算和阶梯匹配逻辑：

1. 找到商品规格适用的采购基准价及报价类型所需的价格配置。
2. 自有品牌报价使用适用的自有品牌配置；客户贴牌报价使用对应客户的个性化配置。
3. 根据商品数量匹配对应价格区间，生成候选价并展示计算依据。
4. 人工逐个产品确认后，该价格才可用于对客户的报价。

配置可以按商品规格和数量阶梯分别维护。贴牌客户的参数或阶梯可以各不相同；没有适用配置时应提示缺失，不能静默套用通用价。自有品牌的规则按品牌、商品还是渠道区分，待确认。

每个数量区间支持直接设置单价，或以基础价格为依据设置百分比加价、折扣等方式计算。各区间可采用不同方式，并展示计算依据及结果。百分比和折扣的具体录入约定、是否支持固定金额加减及组合使用，待结合实际业务确认。

### 5.2 数量阶梯

每个适用价格配置可以设置多个数量档和对应价格或计算参数。系统应校验同一适用范围内的阶梯不重叠、不冲突，并说明数量低于最低档时的处理方式。建议根据订购数量匹配所在区间；价格是整批适用该档单价，还是分段累计，待确认。

报价单可展示多个数量档：每档货款＝该档数量 × 对应的已确认单价。数量单位、价格精度及舍入规则待确认。

### 5.3 价格调整

- **长期调整**：在价格维护中修改相应自有品牌或客户贴牌规则／阶梯价，保存适用范围、生效时间和变更记录，供后续报价使用。
- **仅本次调整**：为当前报价单的特定商品及数量档建立仅本单使用的价格调整记录，保存原因、操作人及时间；它不改变长期价格规则或其他报价。

首期报价单表格不提供直接改单价操作。本次调整通过独立的价格调整入口完成，返回报价单后重新生成候选价并由负责人确认。调整范围或金额变化后，受影响的产品须重新确认，确认时一起展示该产品的全部报价档位。调整权限及本次调整是直接设定单价还是修改计算参数待确认。

## 6. 组合商品价格

维护组成项、规格和每套用量。系统可按采购基准价、自有品牌报价、对应客户贴牌报价等不同口径分别计算参考结果，并展示每项价格来源、数量档和小计。

> 组合参考单价（某口径、某数量档）＝各组成项对应口径的适用单价 × 每套用量之和。

建议组成项以“组合订购数量 × 每套用量”匹配阶梯；是否允许合并不同订单或批次数量待确认。若基础价格或规则缺失，结果标为不完整，并列出缺失项，不能把已知金额当作完整总价。负责人可维护有依据的组合商品人工价格，本次报价仍须逐产品确认。是否同时允许组合商品拥有独立阶梯价格、何时优先使用，待确认。

组成、价格或规则变化时提示复核；新报价使用当前有效数据，已确认报价保留原始快照。变更后是否使已生成但未确认的候选价自动失效待确认。

## 7. 客户与贴牌价格体系

客户资料首期记录客户名称、联系人、联系方式、状态及备注，并可维护客户品牌。客户与商品建立时不要求预先配置贴牌价格。每个客户可按实际报价需要，针对拟报价的商品规格维护专属贴牌规则和数量档；客户之间可以不同。记录配置的适用时间、修改人及修改记录，并可查询客户历史报价。

报价时先查找该客户及商品规格的已有规则；有规则则带出候选价，没有则在价格设置入口按需新增本次所需数量档。价格可以直接设定单价，也可以基于采购基准价按比例计算。负责人确认时，明确选择“保存为客户常用价格”或“仅用于本次报价”；首次设置默认选中前者，允许改选。保存常用价格后，后续同客户、同规格报价自动带出，但每次报价仍需人工确认。仅本次使用的价格不改变长期规则及其他报价。

参考表的客户贴牌页展示同型号、单批次 500 和 1000 个计价单位的单价与货款，并说明部分基础包材及本批次一次性费用已分摊、专项开发另行报价。这些仅为参考表中的具体示例，并非所有客户统一适用的规则。有关费用是否需要纳入系统计算、怎样分摊，需以实际规则确认。

## 8. 客户报价单

### 8.1 流程

1. 选择客户、报价日期及“自有品牌（白牌）”或“客户贴牌”页签；自有品牌报价选择对应品牌。
2. 选择商品规格及采购数量，或选择需要展示的多个数量档；系统根据适用规则生成候选价格和计算明细。
3. 价格、参数或规则缺失时明确提示，不能按零计算。缺少采购基准价时仍可通过价格设置入口直接录入报价，系统标记缺少基准价；在完整展示所报数量档、经人工确认后可用于对客报价。依赖基准价的百分比或折扣计算在基准价缺失时不可计算。
4. 有需要时在长期价格维护或本次价格调整入口处理，并重新生成受影响的候选价格。
5. 负责人逐个产品人工确认生成价格；同一产品的全部报价数量档同时展示，一次确认全部档位。任一档位价格变化后，该产品须重新确认。
6. 所有对外展示的产品价格确认后，生成可对外使用的报价单并导出；留存确认人、时间及价格、规则、商品信息快照。

建议状态：草稿、待确认、已确认、已作废。已确认报价如需调整，建议复制为新版本并重新确认；历史版本不随商品、价格或规则变化而改变。权限和作废规则待确认。

### 8.2 自有品牌（白牌）页签

参考表第一个页签。支持选择自有品牌，展示型号、产品名称、规格／计价单位、线下供货参考价、线上供货参考价、建议零售价／市场指导价、建议首批量及交付说明。支持报价日期、币种、含税与运费说明、服务和交付条款。

线上、线下价格分别使用什么价格配置，市场指导价选取哪一口径，建议首批量如何维护，待确认。

### 8.3 客户贴牌页签

参考表第二个页签。根据对应客户的专属配置，展示型号、产品名称、规格／计价单位、各订购数量档单价及货款、定制说明，以及含税、运费、定制范围和交易交付说明。数量档可配置，不固定为 500 和 1000。未包含的专项费用应明确说明；已分摊进单价的费用不得重复计收。

## 9. 权限与追溯

建议区分商品资料维护、基础价格维护、自有品牌价格维护、客户贴牌规则维护、报价制作、价格调整、报价确认和查看权限；同一人员可拥有多项权限。采购价及财务成本按角色授权查看，不能自动出现在对外报价单中。记录价格变更、单次调整和确认行为，保留历史版本。具体人员和审批层级待确认。

## 10. 首期验收场景

1. 同型号不同规格可分别维护计价单位和价格，并准确进入报价。
2. 采购基准价与出厂价为同一价格，由人工录入；财务含税成本单独维护。采购基准价可生成四种预设加价比例的零售参考价。
3. 两类报价采用相同阶梯匹配逻辑；同一产品可因客户个性化配置而产生不同的贴牌候选价。
4. 组合商品可按不同价格口径显示参考结果及明细；缺价时提示不完整，不按零计算。
5. 新客户无需预设全部产品价格；首次给某客户的商品报价时可按需设置规则，确认时选择保存为常用价格或仅本次使用。保存后下次自动带出且仍需人工确认；仅本次使用不影响长期规则或其他报价。长期调价影响适用的后续报价。
6. 候选价调整后，受影响产品须重新人工确认；同一产品的全部数量档一起展示并一次确认，任一档位变化须重新确认该产品。每个对外展示的产品价格均确认后方可形成对外报价。
7. 白牌页签支持多个自有品牌；贴牌页签使用对应客户的价格配置。多个数量档的货款等于对应数量乘以单价。
8. 缺少适用价格或参数时明确提示，不能以空值或零生成有效报价；采购基准价缺失时允许直接录入报价，经人工确认后对客使用。
9. 已确认的历史报价保留当时数据；不具有成本查看权限的人员和对外报价单不显示采购价及财务成本。

## 11. 待确认问题

1. 百分比和折扣的录入约定是什么？是否支持固定金额加减、多个计算方式组合，以及其他费用？
2. 阶梯价是整批使用对应档单价，还是分段累计？组合商品组成项是否按“组合数量 × 每套用量”匹配阶梯？最低档以下如何处理？
3. 报价确认由哪些角色执行，是否需要区分提交人与确认人？
4. 长期调整与本次调整分别由谁操作、谁确认？本次调整可以直接指定单价，还是只能修改计算参数？
5. 采购基准价调整后，按百分比或折扣计算的客户常用价格是否自动更新，是否需要提示复核？
6. 白牌的线上、线下供货价各使用什么配置？市场指导价取哪个加价比例？不同自有品牌能否对同一商品设置不同价格？
7. 缺少采购基准价时，直接录入的价格是否也允许保存为客户常用价格？
8. 参考报价也必须经过逐产品确认才可对外导出吗？报价单导出格式、有效期、税率和运费条款有何要求？
9. 组合商品能否嵌套、配件能否继续拆分？组合商品是否可拥有独立阶梯价格，优先级如何确定？
