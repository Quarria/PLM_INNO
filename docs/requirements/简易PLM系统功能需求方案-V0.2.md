# 简易 PLM 系统功能需求方案

版本：V0.2（讨论稿）  
日期：2026-11-01  
状态：业务规则待确认，尚未进入架构设计与开发

## 1. 建设目标

统一管理产品资料及采购价、财务含税成本、出厂价和销售价格，减少信息分散、价格口径不一致和客户报价等待时间。系统支持产品、配件、组合商品以及白牌和客户贴牌报价。首期允许基础价格缺失，但对客户使用的报价必须逐次人工确认。

## 2. 首期范围

- 产品、配件和组合商品的资料、规格及组成管理。
- 多种价格、数量阶梯、市场零售参考价及价格历史。
- 组合商品按不同价格口径生成参考价格。
- 客户资料及客户专属贴牌价格体系。
- 白牌和客户贴牌两个报价页签，生成、确认、导出和查询报价单。
- 价格及报价确认、权限控制和操作留痕。

暂不纳入：包装类字段及包装资料管理、销售最小单位字段、报价单上修改单价、自动确认客户报价。贴牌报价所需的定制说明及费用参数属于报价规则，不等同于建立包装物料管理。系统架构、实施计划及自动定价的后期范围待需求确认后讨论。

## 3. 商品与规格

### 3.1 商品类型

| 类型 | 定义 | 组成 |
| --- | --- | --- |
| 产品 | 可独立管理或销售的成品 | 可维护产品及配件组成 |
| 配件 | 产品配套、维修或可独立销售的零部件 | 首期是否允许继续拆分待确认 |
| 组合商品 | 按指定数量将产品或配件组合销售的商品 | 维护各组成项和数量 |

商品类型与组成关系分开管理。标准成品可以有组成；销售套装可以是组合商品。组成不允许形成循环引用。是否允许组合商品嵌套组合商品待确认。

### 3.2 商品字段

| 字段 | 规则 |
| --- | --- |
| 序号 | 列表展示序号，不作为业务编号 |
| 货号／型号 | 商品业务编号；与规格的唯一性规则待确认 |
| 品名、图片 | 维护名称及主图 |
| 规格及描述 | 描述型号、配置等 |
| 单位 | 如台、只、套；报价按具体规格的计价单位展示 |
| 类型、状态 | 产品／配件／组合商品；草稿、启用、停用 |
| 备注、更新时间 | 辅助说明和追溯 |

参考报价表中，同一型号 IHC-K20121 同时存在单只和双只规格，计价单位和价格不同。因此，不能简单将“型号唯一”作为可报价项目唯一性规则。建议以商品加规格区分可报价项目，并分别维护单位、价格与组成；具体编码规则待确认。已有商品停用后不可加入新报价，但历史报价应保留。

## 4. 价格管理

### 4.1 价格口径

| 价格 | 作用与首期规则 |
| --- | --- |
| 采购价 | 采购价格，可暂时缺失；供应商维度待确认 |
| 财务报含税价（成本） | 财务提供的含税成本，可暂时缺失 |
| 出厂价 | 人工录入，独立保存 |
| 基准报价 | 内部维护的销售价格口径，可设置阶梯；具体含义和确认流程待确认 |
| 客户报价口径 | 用于客户或销售渠道的价格，可设置阶梯；与客户专属价的关系待确认 |
| 人工确认价格口径 | 人工维护或确认的价格，可设置阶梯；与单次报价确认的关系待确认 |
| 市场零售参考价 | 根据出厂价与加价比例计算，供内部或报价展示参考 |
| 本次客户报价 | 本次报价单中各商品、各数量档最终经人工确认的价格，保存当时快照 |

以上“基准报价、客户报价、人工确认价格”按用户提出的价格来源保留，名称及相互关系尚未定义，不预设三者相等或可自动互换。价格应明确币种、是否含税、生效时间及计价单位；是否需要税率和失效日期待确认。

市场零售参考价默认以出厂价分别加价 50%、80%、100%、180%，公式为出厂价 ×（1＋加价比例）。出厂价为空时对应参考价不可计算；参考价不是对客报价的自动确认。

### 4.2 阶梯价格

不同价格口径可按商品规格配置数量阶梯，每档维护起订数量和对应单价；建议按数量匹配最高的适用起订档。单价为对应数量档的整批单价，还是分段累计价格，尚待确认。应禁止同一适用范围内重复或冲突的阶梯，并明确未达到最低档的处理方式。阶梯可以缺失，但缺失不可按零计算。

客户报价单可展示多个数量档及各档单价、货款；货款＝该档数量 × 对应单价。价格精度和舍入规则待确认。

### 4.3 组合商品参考价格

维护组成项、规格及每套数量。系统对不同价格口径分别计算参考结果：

> 组合参考单价（某口径、某数量档）＝各组成项对应口径的适用单价 × 每套用量之和。

组成项数量对应的阶梯匹配建议以“组合数量 × 每套用量”为候选规则；是否可以跨商品、跨订单或跨批次合并数量待确认。系统应展示计算明细、来源口径、使用的阶梯和缺失项。

如果任何必要价格缺失，结果标为不完整，不将已知项合计当成完整组合价。负责人可依据线下资料维护组合商品的人工价格，保留原因和依据；本次对客报价仍须另行人工确认。组成项变化或引用价格变化时，相关参考结果提示需复核；具体是否立即阻止使用以及已确认基础价如何失效待确认。

## 5. 客户与贴牌价格体系

### 5.1 客户资料

首期建议记录客户名称、联系人、联系方式、备注和状态，客户可关联其贴牌价格规则。客户名称重复时提示核对；历史报价保留客户当时信息。

### 5.2 客户贴牌价格规则

每个客户可单独配置贴牌价格体系，并按商品或规格、数量阶梯及生效范围维护；避免将通用价格体系直接当作客户贴牌报价。具体规则与字段以实际业务确认后的计算方式为准。

参考表显示：客户品牌定制页按同型号单批采购 500 或 1000 个计价单位列出单价和货款；部分基础包材和本批次一次性费用已分摊入单价，不再重复加收；专项开发另行报价。这些是参考表的示例，不能直接视为所有客户的固定规则。

建议规则至少能够描述：价格来源、适用客户和规格、数量档、定制范围、需要计入单价的费用及其分摊方式、另行报价的项目和生效时间。尚未确认的公式不应默认启用。没有适用规则或参数不全时，应提示缺失并进入人工处理；能否直接维护客户专属阶梯价待确认。

## 6. 客户报价单

### 6.1 共通流程

1. 选择客户、报价日期，在“白牌报价单”或“客户贴牌报价单”页签中建立草稿。
2. 选择商品规格及数量或需要展示的数量档，系统依据对应价格体系生成候选价格及必要提示。
3. 缺失价格、规则或数量档时，明确列出原因，不能以零代替。
4. 提交负责人逐次人工确认，确认前不得生成对外可用的正式报价单；人工确认动作及是否需要逐项确认待明确。
5. 确认后导出、查询，并保存商品信息、价格、规则依据和确认信息的历史快照。

首期不在报价单直接修改单价。如候选价需要调整，返回对应的商品价格或客户贴牌价格维护入口处理后重新生成候选价格，再提交确认；是否需要设置仅适用于某次报价的专用价格入口待确认。已确认报价单需要变更时，建议复制为新版本，重新确认并保留原版本。

确认候选价格并非允许修改报价单价格：确认人审核系统带入的候选价格，调整仍通过价格维护入口完成。

### 6.2 白牌报价单页签

参考表对应“毅诺品牌报价”：按商品展示型号、名称、规格／计价单位、线下供货参考价、线上供货参考价、建议零售价／市场指导价、建议首批量及交付说明。支持显示日期、币种、含税和运费说明、服务与交付条款。白牌在本系统中具体指无品牌、公司自有品牌，还是两者均包括，待确认；参考表明确为毅诺品牌，不能直接认定为无品牌。

线下、线上价格分别从哪个价格口径取得，建议首批量由何处维护，以及是否必须展示多个数量档，待确认。市场指导价是否采用某个加价比例，或人工指定，待确认。

### 6.3 客户贴牌报价单页签

参考表对应“客户品牌定制”：按客户专属规则，展示商品规格、多个订购数量档、各档单价、各档货款和定制说明，并展示币种、含税、运费、定制范围及交易交付说明。数量档由规则配置，参考表的 500、1000 只是示例。专项开发等不包含在基础报价的项目应清楚说明，不重复计入已经分摊的费用。

### 6.4 状态与留痕

建议状态：草稿、待确认、已确认、已作废。记录创建人、确认人、确认时间、报价版本和引用的价格规则；规则或商品后续变化不改写已确认报价的历史内容。报价单是否区分“参考报价／正式报价”，有效期、导出格式和作废权限待确认。

## 7. 角色与权限

建议至少区分商品资料维护、价格维护、客户贴牌规则维护、报价制作、报价确认和查看；同一人可以拥有多个权限。采购价及财务成本应按角色授权查看，避免自动出现在对客报价中。价格变更与确认记录应可追溯。具体人员、授权及审批层级待确认。

## 8. 首期验收场景

1. 录入同型号不同规格的商品，分别维护计价单位和价格，报价时能准确区分。
2. 人工录入出厂价后，按 50%、80%、100%、180% 生成零售参考价；缺失出厂价时不生成有效结果。
3. 对商品不同价格口径维护多个数量档；选择数量后按最终确认的阶梯规则匹配，并显示所用价格来源。
4. 建立组合商品，按不同价格口径分别展示计算明细；缺价时提示不完整，不将缺价当零。
5. 缺价情况下维护有依据的人工组合价格后，仍需逐次确认客户报价才能对外使用。
6. 同一商品面向不同客户，可按各自贴牌规则产生不同数量档候选报价；无规则或参数不足时明确提示。
7. 白牌及贴牌两个页签分别展示对应内容；贴牌数量档的货款等于对应数量乘以单价。
8. 未经人工确认的报价不能作为对外正式报价导出；确认后历史内容不因商品或规则调整而变化。
9. 报价单内不能直接修改单价；调整后重新生成并再次确认。
10. 无成本查看权限的用户和对外报价单均看不到采购价及财务成本。

## 9. 待业务确认的问题

1. “白牌”是无品牌、毅诺自有品牌，还是都包括？参考表的毅诺品牌页应如何归类？
2. 基准报价、客户报价、人工确认价格各指什么？客户报价是通用渠道价、客户专属价，还是历史报价？哪些价格需要预先确认？
3. 贴牌价格实际怎么算？请提供一个客户、一个商品、两个数量档的计算例子，注明基础价、加价／折扣、一次性费用、分摊数量及含税口径。
4. 阶梯价按整批适用单价还是分段累计？组合商品中的组成项是否按组合数量乘以组成用量匹配？最低档以下如何处理？
5. 报价单需调整价格时，维护的价格是更新通用或客户长期价格，还是可以只适用于本次报价？后者如何在不直接修改报价单的前提下维护？
6. 白牌报价表的线上、线下供货价分别来自什么价格？市场指导价应取哪个加价比例？
7. “人工确认报价”由谁确认，是整张单一次确认还是每项／每档逐一确认？参考报价也必须确认后才能对外导出吗？
8. 客户报价单的导出格式、有效期、税率、运费与交付条款是否沿用参考表，或需要按客户配置？
9. 是否允许组合嵌套、配件继续拆分；供应商是否需要分别维护采购价？
