# 精密台账精修版：设计与验收记录

北极星：让产品与报价像一份清晰、可信、适合长期阅读的精密台账。

使用者是内网业务人员；主任务为查看待办、维护产品资料、制作及确认报价。主操作为新建报价。沿用既定导航、统计分栏、待办与常用入口、报价表格和三步表单；保留暖纸色、石墨色、朱砂红与宋体标题。

视觉规范：画布 #f7f6f2，内容纸面 #fffefa，文字 #252c29，辅助文字 #646862，主操作 #9c402f，边线 #dedfd7。浅绿色 #f0f2e9 仅用于常用入口、表头及流程提示，以区分工作区域；状态依旧有明确文字。控件圆角 4px，主要操作高度 44px；中文正文和常用操作 14px，辅助信息 13px，状态标签 12px。宋体只用于页面标题，单号和金额采用等宽及表格数字。

原有米灰大色面、密集粗线和 10–12px 辅助文字导致页面偏闷、扫描负担大。精修提亮纸面、收敛边线、加大字号；去掉无业务含义的英文眉标、装饰编号、重复的“报价待办”标签及页脚口号。原有业务提示与状态保留。没有添加氛围图，当前任务依靠准确的数据表达。

保留旧版：visual-preview.html；本版：refined-preview.html。共享 Vue 组件只增加可选 refined 属性以调整装饰箭头，其余改动在独立样式与入口。

动效：按下用背景及内阴影反馈；表格行悬停及筛选下划线短过渡；弹窗 180ms 轻入，侧栏 220ms 从右侧轻入。沿用原型，不增加整页入场或转场。减少动态效果时禁用动画和过渡。

原型限制：虚构数据、内存状态，刷新恢复初始数据；商品、价格、客户编辑和正式 API、Excel 导出均未接入。当前只评审视觉，不能用于业务核价。

证据通过宿主浏览器工具取得：before.png 为 1440px 基线，workspace.png 为精修整页，form.png 为表单，mobile.png 为 390px 整页。宿主要求浏览器交互使用 cua_repl，所以没有运行启动独立浏览器的 shoot.mjs；本轮不宣称具备该工具的 lint、录屏或测量报告。
