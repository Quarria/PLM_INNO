# PLM 界面预览 v1

预览地址：http://127.0.0.1:5173/design-preview.html
启动：在项目根目录运行 npm run dev -w frontend。
入口：frontend/design-preview.html；界面文件：frontend/src/preview/。

## 设计方向

以日常产品维护和客户报价为中心。沿用绿色品牌识别，使用白色侧栏、浅灰工作区、统一表格和状态标签。主操作为新建报价，工作台优先展示待确认事项。中文采用系统字体，无外部字体或素材依赖。

ui-ux-pro-max 检索建议采用扁平风格和高密度后台布局。返回的营销页章节与电商字体建议不适用于本项目，未采用。

## 本版范围

覆盖工作台、客户报价、产品资料、客户与品牌、价格规则五个页面。提供报价搜索及状态筛选、商品搜索及分类、商品资料弹窗、新建报价三步流程、草稿生成、提交确认、逐产品确认交互。

本版使用虚构业务数据，状态只保留在当前页面内存，刷新恢复初始内容。报价明细采用固定展示数据，尚未与新建表单的商品和数量档统一绑定，不能用于业务核价。客户贴牌品牌暂为单一固定选项，未实现客户品牌关联约束。权限为管理员展示视角。

本版未实现商品、客户、品牌、价格规则的新增编辑、登录、权限管理、报价重算与版本复制、Excel 导出、正式 API 接入。报价日期及有效期的完整业务校验留待接入。现有业务入口及后端未改。

## 视觉方案 B：精密台账

预览：http://127.0.0.1:5173/visual-preview.html 。原绿色方案保留在 design-preview.html。

沿用相同 Vue 界面与流程，通过独立入口 ledger.ts 加载 ledger.css。暖纸色、石墨色、朱砂红构成整体配色；连续统计分栏、档案编号、细线、直角控件建立台账语言。标题用系统宋体，正文保持无衬线，编号和数字使用等宽字体。红色作为品牌和主操作色，状态另用带文字的黄、绿、灰标签。

本轮仅改变视觉呈现，不改业务流程。技能检索匹配 Minimalism & Swiss Style；营销页结构不适用，未采用。复用原有原型交互及其限制。

验证：前端类型检查通过；查看 1440px 工作台、新建报价弹窗、390px 窄屏完整页面。未进行独立视觉评审。本轮未做后端联调。
