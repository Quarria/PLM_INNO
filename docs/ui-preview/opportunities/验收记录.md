## API 验证范围

- 新建默认进入打样；商品规格与同客户报价关联、客户名称及真实权限返回。
- 五节点顺序推进，包括合同进入完成；合同结案说明必填，无有效单据时说明必填。
- 多张单据、附件关联、作废及有效单据统计；历史节点补录不改变当前节点。
- 客户反馈需修改时禁止无说明推进；退回打样新开执行轮次，旧单据保留，未来节点禁止录单。
- 完成后可补录，不能普通推进、修改基本信息或作废历史单据；终止保留停留节点及原因。
- 两个并发推进请求只成功一个；同一请求重放不重复推进。
- 负责人、其他业务员、只读人员、无权限人员及仅持有管理权限的账号分别校验。
- PDF 与 XLSX 附件、伪装格式拒绝、中文下载响应头和原始内容校验。
- 中文文件名“打样检测报告.pdf”“大.pdf”和扩展拉丁字符“café.pdf”正确保留。
- 过期暂存附件随后续上传清理；未登录或无权限下载拒绝，跨商机附件 ID 拒绝。
- 商机完成不改变原有报价确认状态，不自动建立销售订单。

## 浏览器验证范围

- 真实登录入口进入商机管理，主动创建商机并自动打开打样节点。
- 录入打样单据后仍停留在打样；手动推进至送样后，刷新整页自动恢复同一商机并选中送样。
- 点击打样查看历史时，顶部仍显示送样是当前节点。
- 无单据推进按钮在未填写原因时不可提交；填写后可进入客户反馈。
- 客户反馈退回打样后默认显示第二轮，展开历史轮次可查看第一轮单据。
- 全状态筛选可查看已完成及已终止商机；已完成商机隐藏编辑和普通流转入口，保留补录。
- 合同单据的结构化金额、编号正确回显；商机概况可查看关联商品规格和报价编号/状态。
- 1440×1000 桌面布局与 390×844 窄屏布局检查；步骤在窄屏内可横向查看。
